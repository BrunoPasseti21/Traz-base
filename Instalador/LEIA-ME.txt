Traz Base - Instalador

O arquivo TrazBase-Setup.exe é distribuído separadamente deste ZIP.

Alternativa por arquivo ZIP
1. Extraia o pacote completo para uma pasta local.
2. Execute Instalar.bat e escolha a pasta de destino na janela exibida.
3. Aguarde a cópia dos arquivos e a criação do atalho no menu Iniciar.

O pacote inclui o runtime do .NET necessário para Windows x64; não é necessário instalar o .NET separadamente.
O serviço Firebird local precisa estar instalado e ativo para as operações de banco de dados.
